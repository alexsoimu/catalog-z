# Catalog-Z (Photo & Video Template)

A responsive front-end layout for a photo and video catalog website, built as part of a web development practice course.

## 🛠️ Built With

- **HTML5** – Semantic structure of the web page
- **CSS3** – Custom styling, Flexbox, and CSS Grid layout
- **FontAwesome** – Icons for navigation, search, and social media links

## ✨ Features

- **Responsive Navigation Bar:** Includes a logo, page links (Photos, Videos, About, Contact), and mobile-friendly adjustments.
- **Hero Search Section:** A styled search bar with a background image.
- **Photo Grid Gallery:** Displays a clean grid layout of photos accompanied by metadata (upload date and view counts).
- **Pagination Controls:** UI buttons for navigating across different catalog pages.
- **Comprehensive Footer:** Features company info, quick links, social media icons, and policy links.
- **Media Queries:** Fully responsive design adapting to various screen sizes.
